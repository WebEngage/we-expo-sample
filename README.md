# WE Shop

A realistic Expo shopping app used as a test bed for the Expo integration skill.

Branches (all created from `shop/baseline`):

| Branch | Content |
|---|---|
| `shop/baseline` | The app with no analytics or engagement SDK |
| `shop/we-init` | SDK initialised only |
| `shop/we-quick` | Every goal and channel at Quick scope |
| `shop/we-full` | Every goal and channel at Full scope |

## Stack

- Expo SDK 55, React Native 0.83, TypeScript, expo-router
- Local mock data and AsyncStorage persistence, with no backend
- Android package `com.webengage.reactSample`, iOS bundle id `com.webEngage.prodSwift`
- Native folders are generated by `expo prebuild` and are not committed

## Run

```sh
npm install
npx expo run:android   # or: npx expo run:ios
```

Demo login: `demo@weshop.com` / `demo1234`. You can also sign up or continue as a guest.

## Screens

- **Auth:** welcome, login, sign up, guest
- **Home:** Shop Now hero, categories, promo strip, featured and trending products, notifications bell
- **Search:** recent searches, category filter, sort
- **Product:** size and colour variants, quantity, Add to Cart, Buy Now, wishlist, share
- **Cart and checkout:** quantities, coupons (`WELCOME10`, `FLAT50`), addresses, payment method, order confirmation
- **Account:** profile, orders, wishlist, addresses, notifications inbox, notification settings, logout
- **Test Lab:** compose a custom event, screen view or user attributes with typed values

Login, sign up, profile, search, product actions and checkout each have an **Add custom data** section
(attribute name, value and type: string, number, boolean, date, array).
